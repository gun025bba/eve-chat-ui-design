# 로고 콘셉트 (앱 이름 미정, 임시 이름 “Lumen”)

다크 모드 우선의 Apple 스타일 미니멀 로고입니다. 모든 마크는 100×100 그리드에 그렸고, 16·32px 파비콘과 180px 홈 아이콘에서 형태가 읽히는지 확인했습니다. 다른 브랜드나 기기를 연상시키는 형태는 피했습니다(예: 초기 시안이었던 '세 개의 호'는 RSS 아이콘과 너무 닮아서 폐기).
- 전체 비교: `overview.png`
- 콘셉트별 파일: `mark.svg` / `mark-light.svg` (원본), `preview-dark.png` / `preview-light.png`, `app-icon-1024.svg/.png`, `ios-mockup.png` (180/120/60/32/16px, 다크·라이트 배경)
- 다시 생성: `python3 build.py` (rsvg-convert 필요). 앱 이름은 `NAME` 변수로 바꿉니다.
- 색: 액센트 #0A84FF, 그라디언트 #0A84FF→#BF5AF2→#FF9F0A, 아이콘 배경 #1C1C1E

| # | 콘셉트 | 방향 | 노트 |
|---|---|---|---|
| 01 | Orb | 심볼(그라디언트) | 로컬에서 조용히 빛나는 하나의 구. 앱 빈 화면의 컬러 원과 같은 아이덴티티이고, 하이라이트 점이 '항상 켜져 있는' 존재감을 줍니다. |
| 02 | Bubble · Cursor | 심볼(라인) | 말풍선 안에서 깜빡이는 커서로, 답이 스트리밍되는 순간을 보여줍니다. 16px에서는 회색 텍스트 줄을 빼고 커서만 남긴 단순화 버전을 권장합니다. |
| 03 | Monogram l· | 모노그램 + 워드마크 | 소문자 l과 점: 'local'과 이름 첫 글자를 겹쳤습니다. 타이포 중심 방향(`wordmark-dark/light.svg`, Inter 600; 최종본은 글자를 아웃라인 처리). |
| 04 | Thought Wave | 추상 | 부드러운 파동이 점으로 끝납니다. 생각이 흘러 답으로 맺히는 리듬을 표현했습니다. |
| 05 | Dialogue | 기하 | 채워진 반원(답)과 열린 반원(질문)이 마주 보며 하나의 원을 이룹니다. |

추천: 앱 아이콘으로는 **01 Orb**(작은 크기에서 가장 강하고 기존 UI와 일관됨), 문서·웹에서는 **03 워드마크**를 함께 쓰는 조합.

## 이름 후보
1. **Lumen**: 빛의 단위. 어두운 화면 속 작은 빛이라는 Orb 콘셉트와 맞습니다.
2. **Hearth**: 집의 화로. 내 서버에서 도는, 따뜻하고 사적인 AI라는 뜻입니다.
3. **Murmur**: 나지막한 속삭임. 조용하고 개인적인 대화의 톤을 담았습니다.
4. **Locus**: '장소'라는 뜻의 라틴어. 로컬(내 자리)에서 동작한다는 점을 강조합니다.
5. **Ember**: 꺼지지 않는 불씨. 항상 켜져 대기하는 모델의 은유입니다.
6. **Quill**: 깃펜. 글을 써 내려가는 스트리밍의 감각을 표현합니다.
7. **Nook**: 아늑한 구석. 나만의 작은 AI 공간이라는 뜻입니다.
8. **Still**: 고요함. 미니멀하고 방해 없는 경험이라는 디자인 철학을 그대로 담았습니다.
(상표 충돌 여부는 확정 전에 별도로 확인해야 합니다.)
