# 로고 v4: 에메랄드 · 블랙 · 실버

v3 피드백("첫 번째는 너무 토스 느낌", "에메랄드 계열 색으로")을 반영했습니다. 색감은 청록 에메랄드 계열만 참고했고, 특정 팀의 별, 줄무늬 같은 브랜드 요소는 쓰지 않았습니다.
- 다크: 에메랄드 #00D2BE, 실버 그레이 #C4C9CF, 블랙 #0B0B0C (아이콘 배경)
- 라이트: 진한 틸 #007A72, 니어블랙 #121417
- 대비(WCAG): #00D2BE는 #0B0B0C 대비 10.3:1, #007A72는 흰 배경 대비 5.2:1(AA 통과), 실버 #C4C9CF는 #0B0B0C 대비 11.8:1. 밝은 배경에서 #00A19C는 3.2:1밖에 안 돼서 쓰지 않았습니다.
- Drop은 **제외**했습니다. 둥근 원에 한쪽만 뾰족한 말풍선 형태가 토스를 닮은 핵심 원인이라, 색만 바꿔서는 해결되지 않습니다. 형태를 완전히 바꾸면 사실상 새 콘셉트가 되므로, 검증된 두 형태에 집중했습니다.
- 파일(콘셉트별): `mark.svg`, `mark-light.svg`, `mark-mono-dark/light.svg`, `mono-preview.png`, `preview-dark/light.png`, `app-icon-1024.svg/.png`, `ios-mockup.png`. 다시 만들려면 `python3 build.py && python3 compare.py`(compare.py가 v3와 v4를 나란히 놓은 `overview.png`를 만듭니다).

| 01 | Monogram l | v3 Monogram과 같은 형태를 실버 획과 에메랄드 점으로 다시 칠했습니다. 블랙 위에서 차분하고 정밀한 인상입니다. 워드마크 포함. |
