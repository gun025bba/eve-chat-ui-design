# 로고 v3: 부드러운 베이스 + 샤프한 디테일 하나

v2 피드백("너무 각졌고, 뭔가 너무 많다")을 반영했습니다. v1처럼 둥근 형태를 기본으로 하고, 날카로운 디테일은 하나만 넣었습니다(뾰족한 끝 또는 컷 하나). 요소는 최대 두 개, 면 분할과 장식 점은 없습니다. 색은 솔리드 블루이며, 그라디언트는 쓰지 않거나 아주 은은하게만 씁니다. 16/32px부터 설계하고 180px에서 확인했습니다.
- 색: 블루 #3D8BFF(어두운 배경용), #0B4FE0(밝은 배경용), 네이비 #0A1A3A, 아이콘 배경 #0A1428
- 파일: `mark.svg`, `mark-light.svg`, `mark-mono-dark.svg`, `mark-mono-light.svg`(단색), `mono-preview.png`, `preview-dark/light.png`, `app-icon-1024.svg/.png`, `ios-mockup.png`, 그리고 `overview.png`. 다시 만들려면 `cd v3 && python3 build.py`.

| # | 콘셉트 | 노트 |
|---|---|---|
| 01 | Drop | 원에서 한 모서리만 뾰족하게 남긴 하나의 면입니다. 원이면서 말풍선으로도 읽히고, 16px에서 실루엣이 가장 분명합니다. 단색으로도 그대로 쓸 수 있습니다. |
| 02 | Monogram l | 둥근 l 획에 윗부분 사선 컷 하나만 더하고, 블루 점 하나를 두었습니다(요소 2개). 워드마크 포함. |
| 03 | Bubble | 둥근 말풍선 외곽선에 꼬리만 뾰족하게 했고, 안에는 글 첫머리의 커서 하나만 남겼습니다(요소 2개). |

추천: 앱 아이콘 **01 Drop**(가장 단순하고 작은 크기에 강함), 타이포/문서에는 **02 Monogram**.
