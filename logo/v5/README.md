# 로고 v5: 메신저 느낌 빼기

v4 피드백("버블이 낫지만 너무 메신저 느낌")을 반영했습니다. v4 Bubble에서 말풍선 꼬리를 없애고, 커서(생성 중인 생각)를 중심에 두었습니다. 샤프한 디테일은 획 끝을 잘라낸 단면 정도로만 썼습니다.
- 색: `emerald/`(기본. #00D2BE / #007A72, 실버 #C4C9CF, 블랙 #0B0B0C)와 `blue/`(v3 팔레트) 두 벌. 단색 버전 포함.
- 파일: `{emerald,blue}/<변형>/`에 `mark.svg`, `mark-light.svg`, `mark-mono-dark/light.svg`, `mono-preview.png`, `preview-dark/light.png`, `app-icon-1024.svg/.png`, `ios-mockup.png`. 비교 시트는 `overview.png`(에메랄드와 블루, 180/32/16, 다크·라이트).
- 다시 만들려면: `python3 compare.py` (두 팔레트를 모두 빌드하고 overview와 실루엣 체크를 만듭니다).

| # | 변형 | 노트 |
|---|---|---|
| 01 | Open Frame | 꼬리를 없애고 외곽선의 왼쪽 아래를 열어 두었습니다. 닫히지 않은 틀은 '아직 생성 중인 답'을 뜻하고, 잘린 두 획 끝이 샤프한 디테일입니다. |
| 02 | Corners | 대각선의 두 모서리 괄호만 남기고 커서에 초점을 모았습니다. 대화 앱보다는 생각하는 도구에 가깝습니다. 다만 카메라의 스캔·초점 아이콘과 비슷하게 읽힐 수 있습니다. |
| 03 | Cursor Tile | 외곽선 없이, 윗부분이 사선으로 잘린 커서 하나만 둔 가장 단순한 버전입니다. 16px에서 가장 강하지만, v4 Monogram의 l 획과 닮았습니다. |

## 메신저 실루엣 체크
직접 그린 단순화된 일반 형태(실제 로고가 아님)와 단색 실루엣을 비교했습니다. 시트는 `_check/silhouette-check.png`에 있고, gitignore 처리되어 커밋되지 않습니다.
- 메신저 아이콘의 공통 신호는 **꽉 찬 둥근 말풍선과 꼬리**, 또는 원 안의 종이비행기입니다.
- v4 Bubble은 외곽선이지만 꼬리 때문에 메신저 계열로 바로 읽혔습니다. 이것이 피드백의 원인입니다.
- v5의 세 변형에는 꼬리, 타원 면, 종이비행기 모양이 모두 없어서, 16px에서도 메신저 실루엣과 겹치지 않습니다. Open Frame은 둥근 사각 틀이라 말풍선이라는 기억은 약하게 남지만, 메신저 형태는 아닙니다.
- 추천: **01 Open Frame**(v4의 장점을 이어받으면서 메신저 느낌을 뺐습니다), 대안으로 03 Cursor Tile.
