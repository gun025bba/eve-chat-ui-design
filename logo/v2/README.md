# 로고 v2: 샤프 · 블루 톤

피드백("약간 샤프한 느낌, 블루 계열 톤")을 반영했습니다. 둥근 끝과 곡선 대신 직선, 미터(각진) 이음, 사선 절단을 썼습니다. v1의 5개 중 3개(Orb, Bubble·Cursor, Monogram)를 다듬었고, 새 콘셉트 1개(Shard)를 추가했습니다.
- 팔레트: 딥 네이비 #071A47 · #0A1A3A, 일렉트릭 #1F5BFF / #0B3FB8, 아이스 #9BDCFF, 아이콘 배경 #0A1428
- 대비: 어두운 배경에서는 밝은 그라디언트(#1F5BFF→#9BDCFF)와 액센트 #4DA3FF(검정 배경 대비 약 8:1), 밝은 배경에서는 어두운 그라디언트(#071A47→#1F6BFF)와 액센트 #0B4FE0(흰 배경 대비 약 6:1). 배경에 따라 자동으로 바뀝니다.
- 파일 구성은 v1과 같습니다: `mark.svg`, `mark-light.svg`, `preview-dark/light.png`, `app-icon-1024.svg/.png`, `ios-mockup.png`, 그리고 `overview.png`. 다시 만들려면 `cd v2 && python3 build.py`.

| # | 콘셉트 | 노트 |
|---|---|---|
| 01 | Prism (Orb v2) | 구를 육각 결정체로 깎았습니다. 빛을 굴절시키듯 질문을 답으로 바꾸는 모델을 상징하며, 16px에서도 실루엣이 가장 강합니다. |
| 02 | Bubble · Cursor v2 | 직선 말풍선, 사선 꼬리, 각진 블록 커서. 스트리밍되는 순간을 단단한 인상으로 보여줍니다. |
| 03 | Monogram l· v2 | l의 윗부분을 사선으로 자르고 점을 마름모로 바꿨습니다. 워드마크 포함. |
| 04 | Shard (new) | 두 삼각 조각이 사선 틈을 두고 맞물립니다. 질문과 답이 정확히 들어맞는 순간을 표현했습니다. |
